## Overview

Explore Salzburg is a professional WebGIS application developed to visualise and analyse selected public amenities in Salzburg, Austria. The project was refined from a Geovisualization and Advanced Cartography assignment into an interactive web mapping application focused on spatial communication, layer interaction and simple map-based analysis.

## Problem and Motivation

Public amenities such as playgrounds, museums, libraries and Wi-Fi hotspots influence how residents and visitors experience a city. When these datasets are presented only as tables or basic point maps, their spatial distribution and accessibility are difficult to interpret. This project addresses that issue by transforming multiple public datasets into a clear and usable WebGIS interface.

## Data and Application Design

The application uses public geospatial datasets for Salzburg amenities stored as GeoJSON feature collections and JavaScript layers. The interface includes category filters, a search function, popups, feature lists, summary statistics and cartographic symbolisation for different amenity categories.

## Methods and Features

The map was designed with visual hierarchy, clear layer styling and dashboard-like controls. Additional tools support radius-based amenity counting, nearest-amenity identification, distance measurement, CSV export and print-friendly map output. The result is a lightweight browser-based WebGIS built with HTML, CSS, JavaScript and Leaflet.

## Reflection

This project helped me apply cartographic principles in a web environment. It strengthened my understanding of how interface design, symbology, interactivity and spatial analysis tools can improve the communication of urban geospatial data.
