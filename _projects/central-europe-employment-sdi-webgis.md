## Overview

Central Europe Employment SDI WebGIS is a professional WebGIS application developed to demonstrate Spatial Data Infrastructure principles through a comparative employment analysis for Austria and neighbouring Central European countries. It integrates country boundary data with employment statistics and publishes the result as an interactive browser-based geospatial dashboard.

## SDI Context

The project is more than a web map. It demonstrates a compact SDI workflow: spatial data are stored as GeoJSON, employment statistics are stored as JSON, metadata and documentation are included, and users can access the data through a browser-based interface with filtering, mapping, charting and export functions.

## Main Features

The application includes a Leaflet choropleth map, basemap options, year and indicator controls, Austria-versus-country comparison, cartographic classification options, dynamic legends, country labels, interactive tooltips, KPI cards, Chart.js visualisations, an attribute table and CSV export.

## Cartographic and Technical Design

The project applies choropleth mapping, sequential and diverging colour schemes, quantile and equal-interval classification, country highlighting and responsive dashboard design. It was built with open web standards, making it suitable for GitHub Pages deployment without a backend server.

## Reflection

This project strengthened my understanding of how SDI principles can be implemented practically through documentation, metadata, open formats, interoperability and web publication. It also improved my ability to combine cartographic design with analytical dashboard development.
